# Code of conduct

OpenWren follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and patient. Assume good intent.
- Criticise ideas and code, not people.
- No harassment, insults or personal attacks, in issues, pull requests or anywhere else the project meets.

If someone's behaviour makes the project unwelcoming, report it privately to the maintainer through the contact on the maintainer's GitHub profile. Reports are kept confidential. The maintainer may remove comments, close threads or block accounts that break these rules.
